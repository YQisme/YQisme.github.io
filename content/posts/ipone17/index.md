## 相机控制按键

机身右侧下方的一个实体按键，它本质上是一个**压力感应键**，可以通过轻按、重按和滑动来快速操控相机。它的核心价值是让你在横屏拍照时，获得类似传统相机的快门手感，同时解放屏幕取景。

下面从基础操作、高级控制和个性化设置三个方面来介绍它：

### 📸基础操作

这几种核心手势是相机控制键的基础，一旦熟悉，操作效率会高很多：

- **启动相机**：在任意界面（包括锁屏），**按一下**按键即可快速打开相机 App。
- **拍摄照片**：打开相机后，**按一下**按键，就像按传统相机的快门一样。
- **录制视频**：打开相机后，**长按**按键不放，即可开始录制视频；松开则停止录制。
- **调节参数**：在相机取景界面，**轻按一下**（不按到底）：调出**变焦**滑块，显示自拍， 0.5x、1x、2x 等焦段。**轻按两下**（不按到底）并**滑动手指**，可以调节曝光、变焦等参数。

## 全天候显示

第一次看到会觉得“屏幕是不是没关好”，其实它是一个经过精心设计的功能，主要用处如下：

### 一、核心作用：让信息“瞄一眼”就能看到

这是它最主要的价值。你不需要拿起手机、点亮屏幕或做任何操作，**余光一扫就能看到最需要的信息**。

1. **看时间与日期**：手机放在桌上，眼睛瞄一下就能知道几点，比抬手或按键快得多。
2. **查看通知**：短信、微信、邮件等新消息会直接显示在常亮屏幕上。你可以快速判断消息是否重要（来决定是否解锁回复）。
3. **查看实时活动**：正在进行的任务会直接显示：
   - **外卖/打车**：骑手到哪了？司机还有几分钟到？不用解锁，瞄一眼就知道。
   - **音乐/播客**：当前在放什么歌，甚至可以直接控制播放/暂停。
   - **计时器/录音**：还剩多长时间？是否在录音？一目了然。

### 二、便捷作用：与小组件配合，信息面板化

如果你在锁屏界面上添加了小组件（比如天气、日程、健身记录、股票），这些信息也会在常亮屏幕上持续显示。

- **比如**：早上起床，看一眼手机就知道今天几度、有没有下雨、今天第一个会议几点开始。全程不需要碰手机。

### 三、体验作用：让手机更像一个“信息牌”

- **减少操作**：很多原本需要“拿起手机 -> 唤醒屏幕 -> 看信息”的动作，简化为“看一眼”。
- **保持连贯感**：配合动态壁纸，常亮屏幕会变暗但保留色彩和轮廓，不像传统安卓息屏显示那样只是黑色背景上几个白字，视觉上更连贯、更美观。

### 四、如何平衡“实用”与“耗电”

你可能会担心耗电。由于屏幕以 **1Hz** 刷新（每秒只刷新一次，正常使用是 120次）且亮度极低，**官方数据显示它每小时大约多耗电 1%**。大多数用户在实际使用中几乎感觉不到续航变化。

如果你仍觉得不需要，可以随时关闭（**设置 > 显示与亮度 > 全天候显示屏**）。

### 总结一下

| 应用场景        | 没有全天候显示         | **有全天候显示**              |
| :-------------- | :--------------------- | :---------------------------- |
| **看时间**      | 需要点一下屏幕或按按键 | **瞄一眼即可**                |
| **看通知**      | 屏幕亮起才知道有消息   | **屏幕常亮显示通知图标/内容** |
| **看外卖/进度** | 解锁 -> 打开 App       | **锁屏界面直接显示**          |
| **看小组件**    | 解锁或右滑             | **锁屏界面持续显示**          |

**一句话总结：它把 iPhone 锁屏变成了一块安静的、时刻待命的“信息面板”，让你无需任何操作就能获取最常用的信息。**

## 一键抠图

将照片或视频中的人物、动物、物品等主体与背景分离，变成一个独立的、背景透明的素材。效果非常精细，连发丝边缘都能清晰识别。

| 操作方式       | 具体步骤                                                     | 适用场景与特点                                               |
| :------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **长按拖出**   | 在照片中**长按**你想要提取的主体，感觉到触感反馈后，**直接拖动**它到“备忘录”、“信息”等其他App中即可。 | **最经典直观**。可以从一张照片里直接把“人”拖出来放到另一处，操作一气呵成。 |
| **上滑提取**   | 在相册中打开一张照片，**单指从屏幕底部向上滑动**，照片中的主体边缘会闪烁发光。此时轻点发光的**主体**，即可选择“拷贝”或“添加到贴纸”。 | **发现隐藏功能**。上滑照片可以查看详细信息，系统会用发光边框“暗示”你这里可以抠图，很适合探索新功能。 |
| **添加为贴纸** | 通过“长按”或“上滑”调出菜单后，选择 **“添加贴纸”** 。你可以为这个抠图添加**白色外框**、**漫画风**等趣味效果，然后它就会永久保存在你的贴纸抽屉里，随时调用。 | **创造专属素材**。非常适合做手账、在聊天时快速发送趣味表情，或制作个性化照片。 |

- **万物皆可抠**：这个功能不仅能抠人像，猫猫狗狗、花朵、汽车，甚至一个杯子都能精准识别并抠出来。
- **从Live Photo里抠**：在实况照片上操作，还能把其中的一帧提取出来做成**动态贴纸**，发消息时会动，非常有趣。
- **抠图换背景**：利用“添加贴纸”功能，你可以把人像抠出保存为贴纸，然后在另一张背景照片中点击“编辑”，通过“添加贴纸”的方式，将抠出的人像放进新背景里，实现“换背景”效果。
- **视频也支持**：在播放视频时暂停，长按画面中的主体，同样可以把它抠出来。

## 空间场景

给平面照片添加一种“立体的深度感”。

### ✨ 核心效果：让照片“动”起来，有景深感

用一句话解释就是：**把你手机里原本平平无奇的照片，变成一张有前后景深、当你倾斜手机时画面会随之微动的“伪 3D”照片。**

- **怎么玩**：这个功能只对“照片”App里**用相机拍摄的普通2D照片**有效。截屏、屏幕录制、从网页保存的图片都不支持生成3D效果。点击右上角那个 **六边形带箭头的图标**（空间场景按钮），等几秒钟处理完就行了。
- **怎么体验**：处理完后，你**倾斜手机**，就能看到画面中的人物、物体和背景会像有层次一样，随着你的动作产生立体的错位效果。最有意思的是，

### 📱 怎么用起来？

这个功能目前最实用的用法就是做**动态壁纸**，因为苹果的神经网络引擎运算速度很快，体验非常流畅。

操作非常简单：

1. 在“照片”App 里，打开你想设置壁纸的图片。
2. 点击右上角的**空间场景按钮**（六边形图标），生成 3D 效果。
3. 点击左下角的**分享按钮**，选择**“用作墙纸”**。
4. 在预览界面可以确认效果，点击**“添加”**即可。

## 空间视频

“空间视频”和上面的“空间场景”不一样，它是一个**拍摄功能**，记录的是带有真实深度信息的3D视频。

如果说“空间场景”是给普通照片“模拟”3D效果，那“空间视频”就是直接用手机的双摄像头“真实拍摄”一段立体视频。

### 🎬 核心信息一览

| **功能**         | **说明**                                                     |
| :--------------- | :----------------------------------------------------------- |
| **是什么**       | 用主摄和超广角两颗镜头同时录制，模拟人眼视差，拍出有立体景深感的3D视频。 |
| **怎么拍**       | 相机App → 切换到**“空间”模式** → 手机**横着拿** → 按快门拍照或录像。 |
| **怎么观看**     | 在iPhone上直接看只是普通视频，只有用**Apple Vision Pro**观看，才能真正体验那种身临其境的3D效果。 |
| **哪些手机支持** | iPhone 17全系（Pro/标准版都支持），以及iPhone 15 Pro系列和iPhone 16全系。 |

## 辅助功能

不得不说苹果对残障人士的关怀是独一档的，里面的功能太齐全了

### 👀 眼动追踪 (Eye Tracking)

这项功能在 **2024 年随 iOS 18 推出**。

它的设计初衷是为了帮助肢体活动不便的用户，让他们仅用双眼就能操控 iPhone 或 iPad。

**主要特点：**

- **纯软件方案**：直接调用设备前置摄像头，通过端侧机器学习来实现，**不需要额外的硬件**，支持 iPhone 12 及后续机型。
- **操作逻辑**：屏幕上的指针会跟随你的视线移动。当你盯着某个按钮或图标看一小会儿（即“停留控制”），系统就会自动执行点击动作。
- **隐私保护**：所有用于追踪的眼动数据都在设备本地处理，不会与 Apple 共享。

------

### 🗣️ 头部追踪 (Head Tracking)

这项功能在 **2025 年随 iOS 26 推出**，是眼动追踪的进一步延伸。

除了追踪头部移动，它还引入了通过**面部表情**（如抬眉、张嘴、伸舌头等）来触发特定操作的能力。

**主要特点：**

- **启用路径**：`设置 > 辅助功能 > 头部追踪`。
- **操控方式**：移动头部来控制屏幕上的指针，通过“停留”来确认点击。
- **自定义动作**：你可以将“单点”、“返回主屏幕”、“向下滚动”等操作，分别映射到“微笑”、“眨眼”或“伸舌头”等表情上。
- **注意事项**：头部追踪和眼动追踪**不能同时开启**。
